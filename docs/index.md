# AstrBot Developer Docs Index

This is the navigation entry for the installable AstrBot developer skill.
Paths below are relative to this `docs/` directory in the repository, and relative
to the skill root after installation or inside the AstrBot upload zip.

When this repository is installed with `npx skills add`, the CLI discovers
`docs/SKILL.md` and installs this directory as the skill root.

## Start Here

- `design_standards/core_concepts.md`: core AstrBot concepts and plugin architecture.
- `plugin-development-workflow.md`: practical plugin development workflow.
- `plugin_config/command.md`: command filters and plugin handler registration.
- `plugin_config/hooks.md`: plugin event hooks.
- `plugin_config/schema.md`: plugin configuration schema.

## Topic References

- `messages/`: message models, events, and components.
- `platform_adapters/`: adapter interface and message conversion.
- `agent/`: agent runner, tools, personas, subagents, cron, and sandbox behavior.
- `Storage & Utils/`: storage helpers, text-to-image, and plugin i18n notes.
